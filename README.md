# Kevin "Anthony" Felker Portfolio

A modern software engineering portfolio built with Astro and Tailwind CSS, showcasing professional experience, full-stack development projects, and technical skills through a performance-focused, responsive website.

**Live Site:** https://anthonyfelker.com

---

## Overview

This portfolio was designed and developed from the ground up to demonstrate both technical ability and software engineering practices. Beyond presenting my work, the site serves as a real-world example of component-driven architecture, modern frontend development, responsive design, accessibility, SEO, and performance optimization.

The site features custom project case studies, interactive backgrounds, subtle animations, reusable UI components, and a clean information architecture designed to highlight professional experience rather than distract from it.

---

## Features

- Responsive design for desktop, tablet, and mobile
- Custom interactive Aurora-inspired background built with Three.js
- Component-based architecture using Astro

## Why Astro?

Astro was chosen because it enables highly performant, content-focused websites with minimal client-side JavaScript while still allowing interactive components where appropriate. This architecture helps achieve excellent Lighthouse scores while maintaining a rich user experience.

## Local Development

Clone the repository:

```bash
git clone https://github.com/felker12/AstroPortfolio.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:4321
```
